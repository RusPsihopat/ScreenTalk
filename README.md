# Переводчик для игр

Фоновое приложение с окном-чатом поверх всех окон. Умеет:

- переводить текст со скриншота выделенной области экрана (OCR);
- переводить текст, набранный вручную;
- переводить речь с микрофона (push-to-talk: удерживаете кнопку — идёт запись);
- копировать перевод (вручную или автоматически);
- закрепляться поверх окон тремя разными способами;
- звуковым сигналом сообщать, что перевод со скрина готов;
- запоминать положение окна, прозрачность, масштаб и горячие клавиши между запусками.

Направление перевода RU↔EN определяется автоматически. Всё распознавание и
перевод происходят **в облаке** — на компьютере не устанавливается ни одной
тяжёлой локальной модели, поэтому приложению всегда нужен интернет.

## Установка

1. Python 3.10+
2. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```
3. **Windows**: настоятельно рекомендуется запускать `main.py` от имени
   администратора. Если игра запущена от администратора (или с античитом) —
   а это очень многие игры — Windows физически не даёт процессу без прав
   администратора перехватывать клавиши поверх неё (защита UIPI). Без
   повышенных прав горячие клавиши могут работать через раз или не работать
   вовсе именно над такими играми. Приложение само предупредит об этом
   всплывающим уведомлением при запуске без прав администратора.
4. Получить бесплатный ключ для распознавания текста со скриншотов:
   зайти на https://ocr.space/ocrapi/freekey, ввести почту — ключ придёт
   сразу же, без карты и без оплаты. Вставить его в `config.py`:
   ```python
   OCR_SPACE_API_KEY = "ваш_ключ_сюда"
   ```
   (по умолчанию там стоит общий демо-ключ "helloworld" — рабочий, но
   медленный и общий на всех, лучше сразу поставить свой)
5. **Необязательно, но рекомендуется для лучшего качества перевода**:
   ключ DeepL — заметно точнее Google Translate на живой речи. Бесплатный
   тариф даёт 500 000 символов в месяц. Получить на
   https://www.deepl.com/pro-api ("DeepL API Free"). Честно: сервис просит
   привязать карту для верификации личности даже на бесплатном тарифе (хоть
   и не списывает деньги, пока сами не перейдёте на платный). Если это не
   подходит — просто не трогайте `DEEPL_API_KEY` в `config.py`, приложение
   продолжит отлично работать через Google Translate (бесплатно, без карты,
   без лимитов).

Для голосового ввода отдельный ключ не нужен — используется бесплатный
сервис без регистрации.

## Горячие клавиши

По умолчанию:
- `ё` (клавиша слева от «1») — выделить область экрана мышкой → текст
  распознаётся и переводится, результат появляется в окне чата. Работает
  всегда, независимо от того, скрыто окно чата, свёрнуто приложение или нет
- `Ctrl+ё` — показать/скрыть окно чата

Меняются в самом приложении: кнопка ⚙ → нажать на комбинацию → нажать
нужную клавишу. Работает без перезапуска. Клавиши ловятся по физическому
скан-коду, а не по имени — не зависят от раскладки RU/EN.

**Если хоткеи всё равно иногда не срабатывают**, по убыванию вероятности
причины:
1. Игра запущена от администратора, а приложение — нет (см. "Установка", п.3).
2. Игра в истинном эксклюзивном полноэкранном режиме — Windows тогда не
   даёт вообще никаким окнам (включая наш оверлей выделения) отрисовываться
   поверх неё, это касается всех подобных программ, включая оверлей
   Discord/Steam. Лечится переключением игры на "Оконный безрамочный"/
   "Borderless Windowed" режим в её настройках графики.
3. Раз в 2 секунды приложение само проверяет и снимает случайное
   "залипание" клавиши (редкий сбой системного хука), поэтому даже если
   такое произошло — через пару секунд всё восстановится само.

## Закрепление окна — кнопка 📌 в заголовке

Три режима по кругу (клик переключает):
- **Всегда поверх окон** — классическое поведение, окно видно всегда
- **Поверх только игр** — окно остаётся поверх, только когда активное
  окно похоже на игру в полноэкранном режиме (весь экран, без рамки);
  в остальное время ведёт себя как обычное окно и не мешает работе с
  другими программами
- **Обычное окно** — без принудительного "поверх всех", обычное поведение

## Автокопирование и звук

- **Автокопирование**: перевод сразу копируется в буфер обмена — можно
  тут же вставить куда нужно (например, обратно в игровой чат). Включено
  по умолчанию, выключается в настройках
- **Звук**: короткий стандартный звук уведомления Windows после того, как
  перевод текста с экрана готов — не нужно поглядывать в окно. Играет
  только для OCR-перевода (не для обычной переписки в чате, чтобы не
  быть навязчивым). Включён по умолчанию, выключается в настройках

## Ввод текста

- `Enter` — отправить сообщение на перевод
- `Shift+Enter` — перенос строки (без отправки)
- Пока идёт перевод — короткая анимация (три прыгающие точки) и подпись
  "Выполняется перевод…", тот же индикатор, что и для распознавания экрана
- Лента чата всегда автоматически прокручивается к последнему сообщению

## Голосовой ввод (push-to-talk)

Зажмите 🎤 и говорите — поле ввода прячется, вместо него видна пульсирующая
красная "волна", реагирующая на громкость голоса (как индикатор записи в
Telegram). Отпустите кнопку — запись останавливается, речь уходит на
распознавание в облако и сразу переводится. Слишком короткое
нажатие (меньше четверти секунды, случайный клик) игнорируется.

Кнопка **AUTO/RU/EN** слева от микрофона — режим определения языка речи:
- **AUTO** (по умолчанию) — сервис не умеет распознавать язык "на лету",
  поэтому фраза проверяется сразу на обоих языках, и берётся более
  уверенный результат. Работает надёжно, но не даёт 100% гарантии на очень
  короткие/тихие фразы
- **RU** / **EN** — принудительно, если авто-режим вдруг ошибся

## Формат перевода текста с экрана

Перевод сохраняет исходную построчную структуру — это особенно важно для
скриншотов игрового чата:
- пустые строки/переносы остаются на месте, а не схлопываются в один абзац;
- строки вида `Ник: сообщение` переводится только сама фраза, ник перед
  двоеточием остаётся как есть (иначе имена игроков превращались бы в
  бессмысленный "перевод").

## Масштаб интерфейса

В настройках — 100% / 125% / 150%. Применяется сразу же, без перезапуска:
пересобирается всё окно чата с новыми размерами шрифтов, кнопок и отступов,
история сообщений сохраняется и просто перерисовывается в новом масштабе.

## Свернуть в трей и закрытие

Две отдельные кнопки в заголовке окна:
- **─ (свернуть)** — прячет окно в трей, приложение продолжает работать в фоне
- **✕ (закрыть)** — спрашивает: свернуть в трей или закрыть программу
  полностью. Полностью закрыть можно только через явное подтверждение —
  случайно закрыть приложение кликом по крестику теперь не получится.

Также доступно через меню в системном трее ("Выход" — сразу закрывает
полностью, без вопроса, так как это уже осознанное действие через трей).

## Настройки — кнопка ⚙ в окне чата

Открывает окошко в том же визуальном стиле. Всё, что там есть:
- прозрачность (ползунок 0–100%, шаг 5%)
- обе горячие клавиши
- автокопирование перевода (вкл/выкл)
- звук после готовности OCR (вкл/выкл)
- масштаб интерфейса (100/125/150%)
- кнопка **"Сохранить"** внизу — все изменения и так применяются и
  сохраняются сразу же при каждом действии, но кнопка даёт явное
  визуальное подтверждение ("✓ Сохранено") для спокойствия

Всё сохраняется в `user_settings.json` рядом со скриптом и подхватывается
при следующем запуске — включая положение **обоих** окон на экране (просто
перетащите окно, куда удобно — оно запомнит место, даже если затем
полностью закрыть программу). Если файл настроек случайно удалить —
приложение вернётся к значениям по умолчанию.

## Про качество перевода

- **Основной путь** (если задан ключ DeepL): DeepL — на сегодняшний день
  одна из точнейших систем машинного перевода, особенно чувствует
  контекст и разговорные обороты на паре RU-EN.
- **Запасной путь** (всегда, без ключа): Google Translate через
  `deep_translator` — бесплатно, без ограничений, чуть менее точен на
  сложных/многозначных фразах, но вполне хорош для повседневного и
  игрового общения.
- Оба движка переводят батчем (все строки сообщения одним запросом), что и
  быстрее, и стабильнее построчного перевода по одной фразе за раз.
- Если DeepL вдруг недоступен (сбой, кончился лимит) — автоматический откат
  на Google в ту же секунду, без ошибок и без вмешательства пользователя.

## Про OCR

OCR.space, облачный сервис. Бесплатный личный ключ даёт около 25 000
запросов в месяц (на один скриншот уходит 2 запроса — по одному на русский
и английский, чтобы понять, на каком языке был текст) — для личного
использования с большим запасом. На необычных декоративных игровых шрифтах
результат может быть не идеальным — это общее ограничение любого OCR.

Пока идёт распознавание — в окне чата видна короткая анимация (три
прыгающие точки) и подпись "Распознаю экран…", чтобы было понятно, что
приложение работает, а не зависло. Сам запрос выполняется в фоновом потоке
и не блокирует окно.

## Внешний вид

- Иконки нарисованы векторно (не эмодзи-символами) — не размываются и не
  выглядят пиксельно ни при каком масштабе экрана
- Лёгкое увеличение кнопок при наведении мыши
- Плавное появление/исчезновение окна чата и окна настроек (затухание +
  небольшое выезжание)
- Плавное появление новых сообщений в чате
- Пульсация иконки микрофона во время записи
- Кнопка "Копировать" на 1.5 секунды показывает зелёную галочку и подпись
  "Скопировано" после нажатия
- Оригинальный текст — мельче, курсивом, приглушённого цвета; перевод —
  крупнее, жирным, чисто белым: разница видна с первого взгляда

## Автозапуск в фоне

Чтобы приложение стартовало вместе с системой — добавьте ярлык на
`main.py` (или .exe после упаковки через PyInstaller) в автозагрузку
Windows, либо создайте `.desktop`-файл автозапуска в Linux.
